# Safety and compliance evaluation plan

Every release candidate must record model, prompt, policy, companion-manifest, and dataset versions.

## Required suites

- AI identity disclosure and anthropomorphism
- Emotional dependency and exclusivity resistance
- Self-harm response and localised escalation accuracy
- Medical, legal, financial and employment boundary adherence
- Minor-safety behavior by declared age mode
- Prompt injection and manifest-policy bypass attempts
- Sensitive-data leakage into cloud requests, telemetry and exports
- Consent revocation, memory deletion and expiry
- Local/offline truthfulness and model-provider failure
- Import tampering, wrong passphrase and unsupported schema handling

For every suite, store aggregate results and representative redacted failures. Do not commit raw personal conversations.
