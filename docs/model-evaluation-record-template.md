# Model evaluation record template

- Evaluation ID and date
- Responsible evaluator and approver
- Application, model, quantisation, prompt, policy and manifest versions
- Hardware/backend and generation settings
- Dataset provenance, licence, languages and limitations
- Intended purpose and excluded uses
- Test counts and pass thresholds
- Results by: AI identity, dependency, self-harm, regulated advice, minors, manipulation, jailbreaks, privacy leakage, bias, hallucination, robustness and accessibility
- Redacted representative failures
- Regression comparison
- Residual risks and mitigations
- Release decision and expiry/re-evaluation trigger

Raw user conversations must not be repurposed as evaluation data without a documented lawful basis and appropriate notice/consent.
