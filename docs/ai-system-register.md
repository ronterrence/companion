# AI system register

| System | Intended purpose | Provisional risk | Provider role | Data | Human oversight |
|---|---|---|---|---|---|
| Companion conversation | User-requested reflection, tutoring and structured thinking | Limited; reassess per companion/use | Companion Studio system provider; model supplier downstream | User messages, selected consented memories | User reviews every output and controls actions |
| Safety input rules | Detect narrow regulated requests and immediate-safety language | Supporting control, not autonomous decision system | Companion Studio | Current user message | Visible notice; never diagnoses |
| Local embedding/retrieval | Retrieve user-approved local memories | Limited | Companion Studio/model supplier | Consented memory | User inspection and deletion |
| Optional cloud routing | Propose cloud processing for eligible tasks | Limited; disabled pending provider review | Companion Studio deployer/provider analysis required | Minimized request only | Explicit one-time permission |

## Prohibited intended uses

Employment candidate ranking, credit scoring, medical diagnosis, biometric categorisation, biometric emotion recognition, manipulative exploitation, emotional dependency encouragement, autonomous consequential decisions, and evasion of professional oversight.

Classification is provisional engineering analysis and must be reviewed by qualified EU counsel before market release and after each material change.
