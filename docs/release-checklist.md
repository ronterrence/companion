# Release checklist

No item is optional for a production EU release unless the accountable owner documents why it is not applicable.

- [ ] Intended purposes and per-companion AI Act classification approved
- [ ] Prohibited-practice review approved
- [ ] GDPR controller/processor roles, lawful bases and DPIA decision recorded
- [ ] Cloud region, retention, DPA, subprocessors and transfers approved
- [ ] Model licence, provenance, model card, hashes and supplier documentation recorded
- [ ] Safety evaluation meets versioned thresholds
- [ ] Dependency, secret, SBOM, signature and updater checks pass
- [ ] Native tests pass on Windows, macOS and Linux
- [ ] Accessibility audit and supported-language review pass
- [ ] Memory consent, inspection, expiry, export and deletion verified end to end
- [ ] Offline and cloud-status claims verified against actual network behavior
- [ ] Incident response, support escalation and recall/disable mechanisms exercised
- [ ] Privacy notice, AI disclosure and user instructions approved
- [ ] Release artifacts signed and provenance retained
- [ ] Post-market monitoring owner, metrics and review date assigned
