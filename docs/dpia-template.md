# Data Protection Impact Assessment template

This template must be completed by the controller before production processing. It is not a completed DPIA.

## Processing description

- Controller, processors, joint-controller analysis
- Intended purposes and user groups
- Data flows for local inference, cloud inference, memory, export, telemetry and support
- Categories of data subjects and personal/special-category data
- Storage locations, recipients, subprocessors and international transfers
- Retention and deletion schedule

## Necessity and proportionality

- Lawful basis per processing purpose
- Why each data element is required
- Alternatives requiring less personal data
- User notice, consent where applicable, and withdrawal mechanics
- Access, correction, portability, objection and erasure handling
- Children and vulnerable-person safeguards

## Risk assessment

Score likelihood and severity before and after controls for confidentiality loss, incorrect inference, manipulation, dependency, discrimination, unauthorised cloud transfer, excessive retention, inability to delete, model memorisation and re-identification.

## Controls and approval

Document encryption, key management, access control, minimisation, local defaults, human oversight, testing, incident response, processor contracts, residual risks, DPO consultation and supervisory-authority consultation if required. Record owner, approval date, review date, version and material-change triggers.
